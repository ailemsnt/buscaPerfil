# 🔎 GitHub User CLI
### Buscador de perfis do Github

CLI em Javascript para buscar usuários do GitHub e salvar dados localmente em um arquivo JSON.

## 📚 Objetivo

Projeto desenvolvido para estudos - curso Desenvolvimento Back-end SCTec

---

## 💡 Como funciona
1. Digite o username do GitHub
2. O sistema busca na API do GitHub
3. Exibe os dados do usuário
4. Pergunta se deseja salvar
5. Salva no arquivo database.json (sem duplicar registros)

---

## 🛠️ Tecnologias utilizadas

- JavaScript

---

## ⚠️ Regras do sistema
- Não aceita usernames inválidos
- Não salva usuários duplicados
- Trata erros de API e conexão

---

### 🔎 Exemplo de uso
```
Digite o nome do usuário no GITHUB:
usuariogithub

Usuário encontrado: usuariogithub
Deseja gravar? (S ou N)
```
---

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone git@github.com:ailemsnt/buscaPerfil.git
```

2. Pelo VS Code, acesse a pasta do projeto:

```bash
cd busca_perfil
```

3. Após abrir o projeto, execute o arquivo `main.js`.
